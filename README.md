# Tic Tac Toe Android Game

A classic Tic Tac Toe mobile game built using **Java** and **Android Studio**.  
Supports single-player vs AI and multiplayer modes.

---

## 📱 Features

- Play against **another player** or **Android AI**.
- **Multiple difficulty levels** for AI gameplay.
- **Score tracking** for ongoing games.
- **Interactive UI** with clean design.
- **About screen** with app information.
- Integrated **Google Mobile Ads** (AdMob).

---

## 🛠️ Built With

- **Java**
- **Android SDK**
- **XML Layouts**
- **Google Mobile Ads (AdMob)**
- **AppCompat and Material UI Components**

---

## 📂 Project Structure

- `MainActivity` – Core game logic and UI for gameplay.  
- `StartingActivity` – Launcher activity for choosing game mode.  
- `PlayAginstAnthor` – Multiplayer (2 players) screen.  
- `PlayWithAndroid` – Single-player vs AI screen.  
- `Level` – Difficulty selection screen.  
- `About` – Information about the game.  
- `Main2Activity` – Additional feature screen (optional).
